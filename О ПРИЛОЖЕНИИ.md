# Project Checking — ИНТИ. Учёт проектов

Клиент-серверное приложение для учёта проектов в области проектирования
транспортной инфраструктуры. Сервер — ASP.NET Core 8 Web API + MSSQL,
клиент — WPF (.NET 8). Поддерживаются 4 роли: администратор, менеджер,
руководитель, работник.

## Стек

- **Backend:** ASP.NET Core 8, Dapper (ADO.NET), Swashbuckle/Swagger, CsvHelper
- **БД:** Microsoft SQL Server 2022 (Developer Edition в Docker)
- **Frontend:** WPF (.NET 8), QuestPDF (экспорт PDF)
- **Контейнеризация:** Docker + Docker Compose

## Структура репозитория

```
backend/ProjectChecking.Api/      ASP.NET Core Web API (контроллеры, DTO, сервисы)
client/ProjectChecking.Wpf/       WPF-клиент (Views, ViewModels, Services)
db/init.sql                       Схема БД + сидовые данные (идемпотентно)
docker-compose.yml                MSSQL + API
backend/.../Dockerfile            Образ API
```

## Быстрый старт через Docker Compose

Требования: установлен Docker Desktop / Docker Engine с поддержкой Compose.

```bash
docker compose up --build -d
```

Что произойдёт:
1. Поднимется MSSQL на `localhost:1433` (sa / `Pchk_Strong#Pass1`).
2. Backend поднимется на `http://localhost:8080`.
3. При первом запуске API выполнит идемпотентный `db/init.sql`:
   создаст схему БД, роли, тестового администратора, словари и тестовые данные.

Сразу доступно:
- **Swagger UI:** http://localhost:8080/swagger
- **API health:** http://localhost:8080/health

## Локальный запуск (без Docker)

### Backend

```bash
cd backend/ProjectChecking.Api
dotnet restore
dotnet run
```

По умолчанию API ожидает MSSQL на `Server=localhost,1433;Database=ProjectChecking;User Id=sa;Password=Pchk_Strong#Pass1;...`.
Поменять строку подключения можно в `appsettings.json` или переменной окружения
`ConnectionStrings__Default`. При старте API автоматически выполняет `db/init.sql`,
если установлен флаг `Database:AutoMigrate=true` (включено по умолчанию).

### WPF-клиент

WPF собирается под Windows:

```powershell
cd client\ProjectChecking.Wpf
dotnet run
```

При запуске откроется окно авторизации. По умолчанию адрес сервера —
`http://localhost:8080`; можно поменять прямо в окне входа.

## CSV-импорт (для менеджера)

Эндпоинт: `POST /api/projects/import-csv` (multipart/form-data, поле `file`).
Кодировка — UTF-8, разделитель `;`. Поддерживаются заголовки в обоих регистрах:

```
ActivityName;Customer;Description;LeaderFullName;Status
Проектирование автодорог;ОАО «Мосты и дороги»;Участок М-7;Сидоров Сидор Сидорович;в очереди
```

В клиенте: кнопка **«Импорт CSV»** на экране проектов.

## PDF-экспорт

Менеджер/руководитель/работник могут экспортировать текущий
отфильтрованный/отсортированный/постраничный список проектов
кнопкой **«Экспорт PDF»**. Колонки PDF: тема, заказчик, руководитель,
дата создания, статус, дата завершения.

## Аутентификация

`POST /api/auth/login` → возвращает `token`. Все защищённые эндпоинты
требуют заголовка `Authorization: Bearer <token>`.

В Swagger UI: кнопка **Authorize** → ввести `<token>`.

## Полезные эндпоинты (выдержка)

| Метод | Путь                              | Назначение                                  |
|------:|-----------------------------------|---------------------------------------------|
| POST  | `/api/auth/login`                 | Аутентификация                              |
| POST  | `/api/auth/logout`                | Завершение сессии                           |
| GET   | `/api/account/me`                 | Профиль текущего пользователя               |
| PUT   | `/api/account/me`                 | Обновить ФИО / телефон / email              |
| POST  | `/api/account/change-password`    | Смена пароля                                |
| CRUD  | `/api/users`                      | Управление пользователями (admin)           |
| CRUD  | `/api/activities`                 | Виды деятельности (admin)                   |
| CRUD  | `/api/qualifications`             | Квалификации руководителей (admin)          |
| CRUD  | `/api/leaders`                    | Руководители (admin)                        |
| CRUD  | `/api/workers`                    | Работники (admin)                           |
| GET   | `/api/projects?page=&pageSize=&...` | Список проектов с фильтрами                |
| CRUD  | `/api/projects`                   | Управление проектами (менеджер)             |
| POST  | `/api/projects/{id}/start`        | Начать работу над проектом (рук./менеджер)  |
| POST  | `/api/projects/{id}/complete`     | Завершить проект                            |
| POST  | `/api/projects/{id}/uncomplete`   | Отменить завершение                         |
| POST  | `/api/projects/import-csv`        | Импорт проектов из CSV (менеджер)           |

```bash
docker compose down -v         # + удалить том с БД
```
